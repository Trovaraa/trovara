# Trovara Farm Credits messaging drafts

This folder contains the reviewed customer-facing copy for the Trovara Farm Credits account invitation.

- `Trovara Farm Credits Account Invitation - Draft.docx` is the first revised invitation email.
- `Trovara Farm Credits Account Invitation - Short Draft.docx` is the shorter marketing version used by the implemented invitation flow.
- The short invitation embeds `public/brand/trovara-farm-credits-invitation-card.png` as its reward card artwork.
- The Trovara Farm Credits symbol is stored at `public/brand/trovara-credits-symbol.svg` and uses the existing Trovara leaf-T inside a distinct double-ring token.

The invitation deliberately says that an account has been **reserved**, not created or activated. It also distinguishes survey completion, account activation, a qualifying first purchase, and the refund-window hold before a referral reward becomes available. The drafts state that Trovara Farm Credits are promotional, non-cash credits for eligible products sold by Trovara Farm only.
